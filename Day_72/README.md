## Day 72 - Linear Regression

Today I learned about Linear Regression and understood the mathematical intuition behind how a simple regression model learns the relationship between an input feature and a continuous target variable.

### Topics Covered

- Introduction to Linear Regression
- Understanding the mathematical foundation of Linear Regression
- Relationship between input and output variables
- Line of best fit
- Prediction using Linear Regression
- Simple Linear Regression
- Training a Linear Regression model
- Making predictions using the trained model

### Practical Project

I created a simple Linear Regression model to predict a student's package based on their CGPA.

Input:
- CGPA

Target:
- Student Package

The model learns the relationship between CGPA and package from the available training data and uses that relationship to predict the expected package for a new CGPA.

### Key Concepts Learned

- Linear Regression is used to predict a continuous numerical value.
- The model tries to find the best-fitting straight line through the training data.
- The line represents the relationship between the input feature and the target variable.
- Once the model learns this relationship, it can make predictions for unseen data.
- The mathematical understanding of the model helped me understand what happens behind the LinearRegression() function instead of treating it as a black box.

### Key Takeaway

Today I moved from understanding Machine Learning concepts to building my first simple regression model.

Using CGPA to predict a student's package gave me a practical understanding of how Linear Regression can learn a relationship between an input and a continuous output and use that relationship to make predictions.
